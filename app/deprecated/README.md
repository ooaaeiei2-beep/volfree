# 废弃：Python 手绘图标（2026-10-29）

这里的四个文件**不再参与任何流程**，保留只是为了能回看当时的做法。

## 为什么废弃

图标前后被否了四轮（平白 ⏏ → 等距硬盘盒 → 精修 ⏏ → 图像模型材质稿），
每一轮都是我用 PIL 手绘几何 + 自己的审美判断。最后一轮用户直接指出方向：
**照面板头部那个 30pt 小图标放大就行**——那个图标是「蓝色对角渐变 + 白色 `externaldrive.fill`」。

于是图标改成用 AppKit 渲染 SF Symbol，脚本是 `../make_icon.swift` + `../make_icon.sh`。
这样与面板里那个小图标**同源**，不存在"复刻得像不像"的问题。

## 手绘路线真正的教训

不是审美，是三条实现错误（都已在 `../README.md` 里记了）：

1. 画圆角三角形时靠补 `ellipse`，半径给不够就在底边两端留下两个"耳朵"。
   正解是 `soft_polygon`：尖角画多边形 → 高斯模糊 → 50% 阈值切回。
2. 渐变填充幅度给大了，三角和横条是**两个分开的形状**，按整体 bbox 铺渐变时
   横条明显更暗，看起来像两个不同颜色的元素拼的。
3. 高光直接往 RGB 上加会把通道顶到 255，整图变白；必须做成独立 RGBA 图层再 `alpha_composite`。

否则改了生成脚本却忘了重新打包，预览会照样好看，人就被骗过去了。
